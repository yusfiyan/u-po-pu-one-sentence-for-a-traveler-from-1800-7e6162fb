# One Sentence for a Traveler from 1800

One sentence of at most 200 characters explaining the modern internet to someone arriving from 1800 — built only from things they already know: a road, a library, a post office, a market.

> It is one road joining every library, post office, and market in the world, so a letter, a book, or a voice can reach any door in moments, day or night.

Run: `MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts` — writes `entry.txt` (152 characters, one sentence).
